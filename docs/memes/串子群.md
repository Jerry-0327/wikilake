# 串子群

串子群是由 zju 的一位神人建立的群聊，旨在帮助群友相亲，原名“智能家居科技婚介所”，后改名“杭州26级大学生婚介所”。

后来由该神人的舍友推至[双氧水咸鱼](/people/students/26/双氧水咸鱼.md)，她于 2026/8/25 夜广播至大群，吸引无数串子进入寻找乐子，因而得名“串子群”。

接着，[数滔](/people/students/26/数滔.md)邀请[元泽](/people/students/26/元泽.md)进入，串子群热度达到顶峰。

最后，2026/8/30 夜，[西湖酒蒙子](/people/students/25/罗小黑.md)在群中自爆串子群的本质，群主退群，串子群的故事结束，但串子群至今（2026/9/4）仍然存活。

续：群主于2026/9/20 16：06回归，但串子群热度大衰，在2026/9/25后彻底沉寂。
