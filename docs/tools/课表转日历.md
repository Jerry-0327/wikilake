# 课表转日历

作者：[元泽](/people/students/26/元泽)

项目地址：[MestlakeVniversity/From_docx_to_ics_Evolution_Never_Ends](https://github.com/MestlakeVniversity/From_docx_to_ics_Evolution_Never_Ends)

## 使用说明

1. 导出课表
    1. 打开 [学生门户](https://my.westlake.edu.cn) → 工作台 → 教务系统 → 我的课表；
    2. 点 「打印」 → 「导出」 → 「导出至一个word文件」。

2. 打开 [课表转日历](https://ics.netlify.app)
    1. 点 「打开 .docx」 选择导出的课表 Word 文档；
    2. 点 「解析课表」，在表格里核对并修改；
    3. 设置 「第1周周一」 日期：请按自己学校校历改成本学期开学第一周的周一；
    4. 点「导出 .ics」，得到日历文件。
