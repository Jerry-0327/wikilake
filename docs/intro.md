# WikiLake 公约

**宗旨：推动校园文化氛围的积极发展**

## 总则

欢迎来到 **WikiLake**！为了保障每一位用户的权益，维护健康、客观、理性的校园百科环境，请所有贡献者在编辑前务必知悉并遵守本公约。

### 个人隐私与授权

- **尊重个体**：创建或编辑涉及校园内具体个人（学生、教师、职工等）的词条时，**必须征得本人同意**；
- **严禁人肉搜索**：禁止在**未经许可的情况下**公开他人的联系方式、住址、私人照片或其他非公开个人隐私信息。

### 禁言与红线内容

本站严禁传播以下内容：

- **敏感内容**：严禁发布色情、低俗、血腥暴力及任何违反法律法规的政治敏感内容；
- **人身攻击**：严禁对任何老师、学生、学生组织以及校内外社会机构进行人身攻击、造谣、抹黑或恶意揣测；
- **仇恨言论**：禁止发布任何基于种族、宗教、性别或身体残疾的歧视性言论。

### 网站维护与安全

- **禁止技术破坏**：严禁利用自动化脚本、恶意程序提交超量无意义信息；
- **禁止破坏行为**：严禁恶意清空页面内容、擅自篡改他人词条的客观事实；
- **署名规范**：尊重他人劳动成果，在引用非原创内容时，请注明来源。

## 结语

WikiLake 需要每一位西湖同学的支持。我们鼓励记录真实的校园生活、科研经验和学术知识。让我们共同守护这片净土，为构建更好的西湖大学校园氛围贡献力量！

本公约最终解释权归 WikiLake 团队所有。
